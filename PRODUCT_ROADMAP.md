# Roadmap

This roadmap reflects gaps in the current chat client; it does not include delivery dates.

1. Add session lifecycle tests to complement the secure-key migration coverage.
2. Add session navigation and user-selectable model configuration.
3. Add request cancellation, timeouts, and offline/error states.
4. Evaluate a backend proxy before distributing the app beyond personal use.
5. Resolve dependency advisories without applying an untested Expo major upgrade.
